# 更新记录

按 GitHub 正式发布的版本记录，日期为首次发布日期。历史条目根据对应标签补全；补充说明不改变原标签或安装包。

## v0.0.2 · 2026-11-13

### 新增与改善

- Windows 桌面端增加更新检查、版本提示、下载进度和稍后提醒；下载后校验更新签名，确认安装后重启应用。
- GitHub 账号查询分别提示账号不存在、网络超时、上游故障和请求限流；遇到限流显示等待倒计时，到期后恢复重试。
- 同一账号的并发查询合并处理，重复访问使用短期缓存，减少等待和不必要的 GitHub 请求。
- 攻略与搜索完善加载和失败提示；移动端菜单补充展开状态与辅助说明。

### 问题修复与数据保护

- 修复收藏馆“当前可获取勋章完成率”的统计范围，避免把停发勋章计入分子；历史勋章仍保留在收藏记录和勋章墙中。
- 停止请求未公开支持的成就接口，明确说明官方未提供完整成就数据，避免把“数据不可用”理解为“没有获得勋章”。
- 公开攻略查询只展示已发布内容，避免未发布文章被公开读取。
- GitHub 新登录授权缩减为读取用户资料所需的 `read:user`；已有授权不会自动撤销。
- 加强登录回跳地址检查，开发环境遇到可能损失数据的表结构变更时停止启动，避免自动覆盖已有资料。
- 桌面和移动端打包在 Web 内容导出失败时明确报错，避免将缺失内容的页面作为正常应用交付。

### 安装与升级说明

- 提供 Windows x64 NSIS 安装器和 MSI 安装包，任选一种；附件同时包含更新签名、`latest.json` 更新清单和 SHA-256 校验清单。
- 桌面端需要连接自行部署的 API，默认地址为 `http://localhost:4000/api/v1`；登录、收藏、搜索和在线账号查询依赖该服务。自部署入口见[部署文档](../../deploy/README.md)。
- 更新包使用 Tauri 签名；安装器尚未使用 Windows Authenticode 证书，Windows 可能显示未知发布者。
- 本版本未提供 macOS、Linux、Android 或 iOS 安装包。安装器运行、真实 OAuth 登录及跨版本自动升级尚未完成端到端验收，详见[发布验证记录](v0.0.2-verification.md)。

## v0.0.1 · 2026-11-09

### 首次公开发布

- 提供 GitHub 成就百科，整理 17 枚勋章、16 个等级和 12 篇攻略；支持按状态、分类、难度和关键词浏览。
- 勋章详情集中展示获取条件、等级门槛、操作步骤、资料来源和可信度，区分可获取、历史停发及待验证的信息。
- 提供攻略知识库和全站搜索，帮助查找成就说明、入门指南及贡献建议。
- 支持公开 GitHub 账号资料查询，以及登录后的收藏、个人成就记录、进度追踪和数据导出。
- 提供邮箱注册与登录、GitHub OAuth 配置入口，以及管理勋章、攻略、分类、用户、反馈和日志的后台。

### 平台与部署

- 发布 Web 应用、自部署 API 和共享数据类型，提供 API 文档、本地数据库初始化与种子数据。
- 提供 Tauri 桌面端和 Capacitor Android/iOS 工程，可按对应平台的环境要求自行构建。
- 提供服务部署、健康检查、版本更新和回滚脚本，便于维护自部署实例。

### 使用范围与限制

- 本版本为源码发布，发布页未附带预构建安装包；Windows 用户可选择后续 v0.0.2 的安装包。
- GitHub OAuth 需要配置自己的 OAuth App；生产部署需要配置数据库和服务端密钥。
- 官方 API 不提供完整成就列表，账号查询不能作为完整勋章同步的保证。桌面及移动端工程的存在不表示安装体验已完成验收。
