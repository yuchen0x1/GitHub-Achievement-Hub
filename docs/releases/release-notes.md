# 更新记录

## v0.0.2 · 2026-11-13

- GitHub 账号查询更稳定：网络超时、用户不存在与请求限流分别提示；限流后显示等待时间，避免反复查询。
- 成就数据说明更清楚：官方未提供的数据明确显示不可用，不再被理解为用户没有获得勋章。
- 收藏馆修正当前可获取勋章的完成率，历史停发勋章仍保留在收藏记录中。
- GitHub 新登录授权仅申请读取用户资料所需的权限。
- 桌面端提供更新检查、下载进度、稍后提醒以及签名校验后的安装和重启。
- 攻略与搜索的加载、错误反馈和移动端导航得到改善。
- 开发环境遇到可能损失数据的表结构变更时停止启动，防止自动覆盖已有资料。

Windows 发布附件提供 x64 安装包和更新清单。桌面端需要连接自行部署的 API，默认地址为 `http://localhost:4000/api/v1`；登录、收藏、搜索及在线查询需要该服务可用。更新包使用 Tauri 签名，安装器尚未使用 Windows Authenticode 证书，Windows 可能显示未知发布者。

## v0.0.1 · 2026-11-09

- 首次公开发布 GitHub 成就百科、等级门槛、获取攻略与资料来源。
- 提供公开账号查询、个人收藏与进度记录，以及内容管理功能。
- 提供 Web、自部署 API 和桌面/移动端工程。
