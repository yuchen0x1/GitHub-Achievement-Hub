# v0.0.2 发布检查（2026-11-13）

## 1. 总览

本轮对真实 Web/桌面产物执行静态暴露扫描，检查暂存源码的凭证模式，并用客户端配置中的公钥验证 NSIS/MSI 更新签名及签名内的版本。此报告不是安全认证，也不代表真实跨版本安装验收。

- Web 静态产物：340 个文件、40 个 Web 资源；扫描未发现 source map 或凭证模式。原始扫描得分 100/A 仅表示这些规则未命中，不能推断代码难以逆向。本项目本身公开源代码，不以隐藏客户端代码作为保护目标。
- Windows 原生文件：原始扫描得分 69/C。人工复核后保留 Authenticode 缺失和 CFG 未启用；localhost 是本产品支持的自部署 API 默认地址，PDB 仅有文件名，无构建机绝对路径，不能当作内部地址或源码路径泄漏。
- NSIS/MSI 更新签名：两份均通过公钥校验，可信注释绑定 `0.0.2`。这与 Windows Authenticode 身份签名不同。
- 本地验证：88 项 API 单元/集成测试通过，API/Web 类型检查和桌面脚本语法检查通过，Web 静态导出及 Tauri release 构建成功。实际安装、登录 OAuth、旧客户端升级后重启尚未验收。

## 3. 逐项证据与修复

- `apps/desktop/src-tauri/target/release/github-achievement-hub.exe` 的 PE SECURITY 数据目录为空；安装器未使用系统身份签名。取得受控代码签名证书后，可使用 `signtool sign /fd SHA256 /tr <timestamp-url> /td SHA256 <exe>`，并重新打包及生成更新签名。
- GitHub Dependabot [glob #1](https://github.com/yuchen0x1/GitHub-Achievement-Hub/security/dependabot/1) 指定修复版本 10.5.0。`package.json` 对 test-exclude 的 glob 做定向 override；未把所有 glob 使用者强制降级到旧主版本。
- 剩余告警见 [minimatch #4](https://github.com/yuchen0x1/GitHub-Achievement-Hub/security/dependabot/4)、[glib #5](https://github.com/yuchen0x1/GitHub-Achievement-Hub/security/dependabot/5)、[deepmerge #2](https://github.com/yuchen0x1/GitHub-Achievement-Hub/security/dependabot/2)。这是实际存在的告警；开发依赖/平台范围降低本次 Windows 附件的暴露范围，不等于漏洞不存在。
- `tauri.conf.json` 使用固定 updater 公钥且开启 `requireSignedVersion`。`prepare-release.mjs` 校验文件 BLAKE2b-512 的 Ed25519 签名和可信版本注释后，才生成 `latest.json` 与 SHA-256 清单；未读取私钥。格式依据 [Minisign 规范](https://jedisct1.github.io/minisign/)。
- 原始扫描命中的 `http://localhost:4000/api/v1` 是明确公开的自部署默认地址；`github_achievement_hub.pdb` 仅为文件名，发布附件不包含 PDB 文件。

## 4. 客户端无法解决的问题

- 认证、角色与用户状态检查由 NestJS API 守卫处理，不能依赖客户端隐藏管理入口。客户端代码和公开更新公钥都可以被提取，这不等同于私钥泄漏。
- 自部署者必须维护 API、HTTPS 和服务端密钥；桌面安装包不内置后端数据库或生产凭证。
- 本次只在本地使用已有签名私钥，没有上传到仓库或修改 GitHub Actions Secrets。持续自动打包仍需由仓库维护者配置 Secrets。

## 5. 修复顺序

1. 已完成：排除凭证文件、修补 glob 高危开发依赖、签名及版本核验、重新生成前端以避免旧产物混入。
2. 接续：补真实旧版升级和 WebView 交互验收；配置 Authenticode；在 API 配置范围内验证 CSP。

发布附件包括 x64 EXE、MSI、对应 `.sig`、`latest.json` 和 `SHA256SUMS.txt`；是否公开、远程工作流结果以 GitHub Release/Actions 实际状态为准。
